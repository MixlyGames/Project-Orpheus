# Проект: свой UI для LLM с аватаром

Личный проект, только Windows, не для коммерции и не для публикации.

## Идея
Что-то вроде Claude Desktop, но со своим дизайном, названиями и механиками:
- чат-интерфейс для LLM (API-провайдеры и локальные модели);
- 3D-рендерер для аватара (предварительно: Three.js + VRM);
- 2D-режим (Live2D или спрайты на PixiJS);
- питомец/аватар на рабочем столе (отдельное прозрачное окно Tauri);
- TTS и STT: и через API (например ElevenLabs), и локально через ONNX.

## Стек (предварительно)
- Tauri (Rust) + Vite
- Фронтенд: React + TypeScript (пока в проекте шаблон на чистом TS, переход на React ещё не подтверждён)
- Платформа: только Windows (WebView2)

## План работы
Сначала интерфейс и общий дизайн с функционалом на заглушках, потом реальные модели.

1. Интерфейс чата и дизайн. Вместо LLM заглушка: интерфейс `LLMProvider` + фейковый провайдер, печатающий ответ по буквам (проверка потокового вывода).
2. Чат с реальным провайдером LLM, потоковый вывод.
3. Окно с 3D-аватаром (VRM) без голоса.
4. TTS через API и липсинк.
5. STT.
6. Питомец на рабочем столе (второе окно).
7. Локальные ONNX-модели (TTS/STT) и 2D-режим.

Для TTS и STT сразу делать общий интерфейс «провайдер», чтобы подменять API и локальную модель настройкой.

## Правила работы с ИИ
- Перед крупными правками делать коммит в git.
- Не заходить в `node_modules/` и `target/`.
- Не читать `.env` и любые ключи/секреты.
- Изменения в `src-tauri/tauri.conf.json` и `capabilities/` проверять вручную.
- Сборку и запуск (`npm run tauri dev`, `cargo`) делает пользователь, ошибки присылает или они видны через диагностику.
